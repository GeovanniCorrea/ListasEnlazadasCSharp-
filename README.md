# ListasEnlazadasCSharp
Proyecto de ejercicios de listas enlazadas en C#.

## Contenido
- Program.cs → ejecuta los ejercicios 4 y 5 de los ejercicios propuestos
- Nodo.cs → define los nodos de la lista
- ListaEnlazada.cs → estructura de lista enlazada
- ListasEnlazadasCSharp.csproj → archivo del proyecto C#
